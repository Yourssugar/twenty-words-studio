# Памятка: сервер и Twenty Words Studio

Команды PowerShell пишутся на Windows, команды с `tw`, `sudo` и `systemctl` пишутся на сервере после входа по SSH.

## Где что лежит

| Что | Где |
|---|---|
| Исходники сервера | `Desktop\TW Server` (приватный репозиторий) |
| Приложение студии | `Desktop\TW Studio` (публичный репозиторий `Yourssugar/twenty-words-studio`) |
| Сайт с кузницей | `C:\Users\Adronix\Documents\GitHub\A.C.EON` |
| Сервер | Dell `tw-home`, пользователь `aliaksandr` |
| Адрес для команды | https://studio.twentywordsstudio.com |
| База на сервере | `/var/lib/tw-studio` |
| Бэкапы | 3 последние на сервере в `/var/lib/tw-studio/backups`, остальные в Cloudflare R2, бакет `tw-studio-backups` |

## Зайти на сервер

Дома:
```
ssh aliaksandr@tw-home.local
```
Откуда угодно (через Tailscale, он должен быть включён на ноутбуке):
```
ssh aliaksandr@tw-home
```
Спросит фразу ключа SSH. Выйти: `exit`.

## Обновить сервер

Когда пришёл новый файл `tw-studio` (без .exe):

1. Удалить старый `tw-studio` из "Загрузок", скачать новый. Если браузер назвал его `tw-studio (1)`, переименовать.
2. В PowerShell в папке `TW Server`:
   ```
   powershell -ExecutionPolicy Bypass -File .\scripts\update-server.ps1
   ```
3. Спросит фразу ключа и пароль sudo. В конце должно быть `Служба: active` и `Готово`.

Если скрипт не сработал, вручную:
```
cd $env:USERPROFILE\Downloads
scp tw-studio aliaksandr@tw-home:/tmp/
```
и на сервере:
```
sudo install -m 0755 /tmp/tw-studio /usr/local/bin/tw-studio && sudo systemctl restart tw-studio
tw version
```

Сначала всегда обновляется сервер, потом приложение.

## Выпустить обновление приложения для команды

Когда пришёл архив `tw-studio-app-X.Y.Z.zip`:

1. Открыть архив, зайти в папку `tw-studio-app`, всё содержимое скопировать в `TW Studio` с заменой.
2. Если в сообщении сказано про новые зависимости: `npm install`.
3. В папке `TW Studio`:
   ```
   npm run release
   ```
   Скрипт сам сохранит изменения в git, отправит на GitHub, соберёт установщик и выложит релиз. У команды приложение обновится само.

Проверить у себя без выпуска: `npm start`.

Ссылка на установщик для новых людей (всегда последняя версия):
https://github.com/Yourssugar/twenty-words-studio/releases/latest/download/Twenty-Words-Studio-Setup.exe

Если GitHub CLI просит войти: `gh auth login` (GitHub.com, HTTPS, Yes, Login with a web browser).

## Обновить инструменты кузницы в приложении

Только когда на сайте поменялись Графика, Звук, Монтаж, Страницы или Фоны:

1. В GitHub Desktop у сайта нажать Fetch origin и, если есть, Pull origin.
2. В папке `TW Studio`:
   ```
   npm run pack-tools -- "C:\Users\Adronix\Documents\GitHub\A.C.EON\forge" --upload
   ```
3. Поднять `version` в `package.json` (например, 0.6.0 на 0.6.1) и выполнить `npm run release`.

## Пригласить человека

Обычно из приложения: раздел Админ, "Пригласить человека". Код одноразовый, передавать лично.

С сервера:
```
tw invite -name "Имя"
tw invite -name "Имя" -role admin
```
Забыл пароль: в админке кнопка сброса пароля напротив человека, новый код вводится на вкладке "По приглашению".

## Модели ассистента

Сейчас подключены: GPT и GPT-mini (OpenAI), GLM (Z.ai, бесплатно), Codestral (Mistral, бесплатно, около 2 запросов в минуту).

На сервере, ключ программа спросит отдельно:
```
tw ai-openai      GPT и GPT-mini
tw ai-glm         GLM (бесплатная, без лимита)
tw ai-status      котлы, модели, расход за сегодня, месяц и всё время
```
Заменить ключ провайдера, не трогая модели (например, после перевыпуска ключа):
```
tw ai-provider -name mistral -kind mistral -url https://api.mistral.ai/v1
tw ai-provider -name zai -kind zai -url https://api.z.ai/api/paas/v4
tw ai-openai                (у OpenAI просто ещё раз)
```
Добавить модель к уже подключённому провайдеру и убрать модель:
```
tw ai-model -name codestral-latest -provider mistral -pool codestral -label Codestral
tw ai-model-remove -name mistral-large-2512
```
Убрать модель можно и в приложении: Админ, Ассистент, Модели, кнопка "Убрать".

У Mistral на бесплатном плане работает только Codestral, остальные модели отвечают нулевым лимитом. Проверить заново (ключ спросит скрыто):
```
read -rsp "Ключ Mistral: " K; echo; curl -s -D - -o /dev/null https://api.mistral.ai/v1/chat/completions -H "Authorization: Bearer $K" -H "Content-Type: application/json" -d '{"model":"devstral-latest","messages":[{"role":"user","content":"hi"}],"max_tokens":5}' | grep -i -E "^HTTP|ratelimit"; unset K
```
Если там не 0 запросов в минуту, Devstral подключается одной командой `tw ai-model`.

Ошибки в чате: "ключ не подходит" значит неверный ключ, "модель недоступна в тарифе" значит ключ рабочий, но модели нет в бесплатном плане.
Лимиты, скиллы, установку и объём контекста менять в приложении: раздел Админ, карточка "Ассистент". Галочку "без лимита" для GPT не ставить: сверх бесплатного объёма OpenAI берёт деньги.

## Полезные команды на сервере

```
tw users                                       люди
tw version                                     версия сервера
systemctl status tw-studio --no-pager          работает ли сервер
sudo systemctl restart tw-studio               перезапустить сервер
sudo journalctl -u tw-studio -n 50 --no-pager  последние строки лога
systemctl status cloudflared --no-pager        работает ли туннель
systemctl list-timers tw-backup.timer          когда следующий бэкап
sudo journalctl -u tw-backup -n 10 --no-pager  как прошёл последний бэкап
sudo systemctl start tw-backup                 сделать бэкап прямо сейчас
```

Проверка снаружи, с телефона: https://studio.twentywordsstudio.com/api/health должен ответить `{"ok":true}`.

## Передать файл на сервер и обратно

На сервер (файл окажется в `/tmp`):
```
scp путь\к\файлу aliaksandr@tw-home:/tmp/
```
С сервера в текущую папку на Windows:
```
scp aliaksandr@tw-home:/путь/к/файлу .
```

## Если что-то не работает

1. Приложение не подключается: открыть https://studio.twentywordsstudio.com/api/health. Нет ответа, значит смотреть сервер.
2. Зайти по SSH. Не пускает дома, попробовать `ssh aliaksandr@tw-home` через Tailscale. Не пускает никак: сервер выключен или без сети, нужен монитор и клавиатура.
3. На сервере: `systemctl status tw-studio --no-pager` и `systemctl status cloudflared --no-pager`. Если что-то не `active`, перезапустить: `sudo systemctl restart tw-studio` или `sudo systemctl restart cloudflared`.
4. Не помогло: `sudo journalctl -u tw-studio -n 50 --no-pager` и прислать вывод.

## Что хранить у себя и никому не отправлять

- Строка `AGE-SECRET-KEY-1...`: без неё бэкапы из R2 не расшифровать. Хранить в менеджере паролей и на бумаге.
- Фраза ключа SSH и пароль sudo на сервере.
- Ключи API (OpenAI, Mistral, Z.ai), ключи R2, токен Cloudflare Tunnel: только вставлять в команды, в чат и в файлы не класть.
