# Twenty Words Studio

Рабочее приложение команды: главная с графом идей, чат, ассистент, инструменты кузницы, админка.

Отдельно от публичного лаунчера с играми: студийный код и адрес сервера команды не попадают к тем, кто скачал лаунчер.

## Что есть в 0.6.0

Нужен сервер 0.7.0 и новее.

- Пока модель размышляет или ждёт ответа, в чате видно «Думает» и таймер, потом «пишет» и время. Под готовым ответом написано, за сколько он пришёл.
- Модели без лимита (GLM) показывают «без лимита» и расход за сегодня.
- Админка: у каждого котла галочка «без лимита», расход за сегодня, месяц и всё время. У людей добавлен столбец «Всего».

## Что было в 0.5.0

- Карточка на главной открывается как тема: заголовок, текст и общее обсуждение для всех. В списке ветки видно, сколько в теме сообщений и сколько новых, на кнопке «Главная» общий счётчик непрочитанного. Новая карточка сразу открывается как тема.
- Ассистент: установка для всех чатов задаётся в админке (по умолчанию Aceon_node).
- Скиллы: админ ведёт список, каждый включает нужные галочкой в своём чате (кнопка «Скиллы» над полем ввода). Из коробки есть «Без ИИ-паттернов».
- Блокнот: кнопка «в блокнот» у каждого блока кода и под ответом. Заметки можно править (Ctrl+S сохраняет) и прикладывать к сообщению кнопкой «Приложить» или галочкой в блокноте.
- Рядом с полем ввода видно, сколько примерно токенов уйдёт в модель и сколько можно. Объём для каждой модели задаётся в админке: GPT 64 тыс., GPT-mini 32 тыс., Devstral 64 тыс., остальные 16 тыс.

## Запуск

Нужен Node.js (тот же, что для лаунчера).

1. Запусти сервер из папки TW Server: `.\tw-studio.exe serve`
2. Если в базе ещё нет ни одного админа, создай приглашение себе:
   `.\tw-studio.exe invite -name "Александр" -role admin`
3. В папке TW Studio:

   ```
   npm install
   npm start
   ```

4. В приложении вкладка "По приглашению": код, логин, пароль. Остальных людей дальше можно приглашать из раздела Админ, командная строка для этого больше не нужна.

Установщик для Windows без публикации: `npm run dist`, файл появится в `dist/`.

## Адрес сервера

Адрес задаётся в `data/config.json`: `https://studio.twentywordsstudio.com`. Каждый человек может поменять его у себя на экране входа (строка "Сервер" внизу) или в Профиле. Для проверки с локальным сервером: `http://127.0.0.1:8787`.

http разрешён только для своего компьютера (127.0.0.1, localhost). Любой другой адрес только https.

## Выпуск версии для команды

Репозиторий публичный: `Yourssugar/twenty-words-studio`. Секретов в нём нет, токен GitHub в файлах не хранится.

Один раз на компьютере: поставить GitHub CLI (`winget install GitHub.cli`) и выполнить `gh auth login`.

Новая версия приложения:

1. Поднять `version` в `package.json`, закоммитить, `git push`.
2. `npm run release`. Скрипт возьмёт токен у GitHub CLI, создаст релиз `v<версия>` и загрузит установщик.
3. Ссылка для команды всегда одна: https://github.com/Yourssugar/twenty-words-studio/releases/latest/download/Twenty-Words-Studio-Setup.exe

Установленные приложения сами скачают обновление и предложат перезапуск.

Новые версии инструментов кузницы (когда на сайте поменялись файлы):

1. `npm run pack-tools -- "<путь к forge в репозитории сайта>" --upload`
2. Скрипт соберёт пакеты, запишет их размеры и sha256 в `data/tools.json` и выложит релиз `tools-<дата>`.
3. Закоммитить `data/tools.json` и выпустить новую версию приложения (шаги выше). Пока приложение не обновилось, у людей ставятся прежние пакеты.

## Безопасность

- Интерфейс работает в песочнице (`sandbox`, `contextIsolation`, без Node). В сеть он не ходит вообще (`connect-src 'none'`): все запросы делает главный процесс, интерфейс вызывает только функции из `preload.js`.
- Главный процесс проверяет каждый вызов: типы, длину строк, допустимые действия. Запросы принимаются только от окна самого приложения.
- Токен входа хранится зашифрованным средствами Windows (safeStorage, DPAPI). Скопированный на другой компьютер файл не расшифровать.
- Окно никуда не переходит, новые окна не открываются, ссылки уходят в обычный браузер.
- Камера, микрофон и другие разрешения браузера запрещены.
- Если сервер не принял токен (человека заблокировали, удалили или сменили пароль), приложение сразу возвращается на экран входа.
- Инструменты кузницы открываются в отдельных окнах со своей сессией (`persist:forge`) по адресу `twtool://forge/...`. У этих окон нет доступа ни к токену студии, ни к Node, ни к функциям приложения. Ссылки наружу уходят в браузер.
- Каждый скачанный пакет инструмента сверяется по sha256 с `data/tools.json` внутри приложения. Если не совпало, ничего не распаковывается. Распаковка пишет только в пути, разрешённые этому пакету.

## Как устроено

```
src/main/main.js      окно, IPC, уведомления, хранение токена и настроек
src/main/client.js    связь с сервером (HTTP и WebSocket), без зависимости от Electron
src/main/tools.js     скачивание, проверка, распаковка и окна инструментов кузницы
src/main/updater.js   автообновление установленной программы
src/preload/preload.js  функции, которые видит интерфейс
src/renderer/         интерфейс: index.html, app.js (общее, чат, админ, профиль),
                      home.js (граф), tools.js, assistant.js, themes.js, styles.css
src/assets/           иконка, аватары и фоны тем (из лаунчера)
data/config.json      адрес сервера по умолчанию
data/tools.json       список пакетов инструментов с sha256
scripts/              release.js (выпуск версии), pack-tools.js (пакеты кузницы)
```

Отладка: при запуске через `npm start` работает Ctrl+Shift+I (инструменты разработчика). В установленной версии они выключены.
